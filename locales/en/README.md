# rebirth_biology_en

English edition of rebirth_biology.

https://nanalab.kr/rebirth_biology_en/

The game preserves the original draw weights, retry credits, native sharing and JPG downloads. Shared result links open the home screen; their OG previews show the localized result and probability. Image licenses and source notices remain attached. No Kakao SDK or key is included.

```text
npm ci
npm run build
npm test
```
