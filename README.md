# rebirth_biology

다시 태어나면 어떤 생물로 태어날까: 개체수 자료를 바탕으로 만드는 생물 환생 게임.

현재 단계는 데이터와 이미지 준비다. 앱은 아직 배포하지 않았다.

## 수집 데이터

- 조류 9,700종 세계 개체수 추정과 종별 불확실성 구간.
- 조류 데이터의 속·과·목 집계 2,485행.
- 속·강·과·문 등의 집단 개체수 추정 8개 자료와 범위·단위·중복 관계.
- CC0 관측 사진을 확인한 후보 400종의 출처 URL과 라이선스 메타데이터.
- 퍼블릭 도메인 다시마 삽화 1개.

출처와 적용 제한은 [POPULATION_METHOD.md](POPULATION_METHOD.md)를 참고한다. 공개 데이터의 라이선스는 각 자료에 따른다. 전체 저장소에 일괄 라이선스를 부여하지 않는다.

## 재현

`node scripts/prepare-populations.mjs`로 정규화한 조류 표의 상위 분류군 집계와 후보 학명 대조 결과를 다시 생성한다.

개체수 자료가 없는 종에 동일 가중치나 관측 수 가중치를 부여하지 않는다. 상위 분류군 자료만 있으면 그 분류군 수준의 결과로 다룬다.

## 현재 확률 기준

사용자 요청에 따라 탄소 생물량 기준으로 전환했다. BIOMASS_METHOD.md가 현재 기준이며 개체수 조사 문서는 과거 조사 기록이다. 기본 26개에서 포유류·해양 집단을 세분화한 **72개 결과를 고정**했다. 활성 목록은 `data/categories.json`이다. 인간 확률은 약 0.01008%다. 식물은 1개 집단으로 유지한다.

## 이미지

72개 결과마다 300×300 JPG 이미지가 1개씩 있다. `src/images/categories/`에 저장했다.

- CC0·퍼블릭 도메인 50개.
- 상업 사용과 크롭이 허용된 CC BY 20개. 원 제작자·라이선스·출처·변경 사실 표시를 유지해야 한다.
- 무료 이미지에서 적절한 생물 모습을 확보하지 못한 해양 균류·극미소 원생생물은 생성 개념 삽화 2개로 대체했다. 실물 사진이나 특정 종의 정확한 해부도로 표시하지 않는다.

[이미지 갤러리](image-gallery.html), [전체 출처](IMAGE_SOURCES.md), [전체 미리보기](previews/categories-72.jpg). 원본 URL·라이선스·해시는 `data/category-image-sources.json`, 생성 프롬프트는 `data/image-generation-prompts.json`에 있다.

`npm run assets:verify`로 72개 파일의 JPG 형식·300×300 크기·해시·출처·확률 합계를 검증한다. `npm run assets:gallery`로 출처 갤러리와 미리보기를 재생성한다. 자료 수집 스크립트는 조사 과정용이며, 재실행하면 수동 검수한 선택을 덮어쓸 수 있다. 최종 선택은 위 출처 목록을 따른다.
