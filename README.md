# rebirth_biology

다시 태어나면 어떤 생물로 태어날까? 지구 탄소 생물량 비례로 추첨하는 생물등록증 게임.

- 공개 사이트: https://nanalab.kr/rebirth_biology/
- GitHub Pages: `main` 브랜치 `/docs`, 별도 Actions 빌드 없이 배포.
- 결과 72개, 결과별 OG JPG 72개와 기본 OG 1개.
- 공유 링크는 메인 화면으로 진입하며, SNS 미리보기에는 해당 생물·확률·대표 이미지가 표시된다.
- 첫 추첨 무료, 다시하기 기본 1회. 브라우저에 결과와 잔여 횟수를 저장한다.
- 결과마다 공유 보너스 +2회는 한 번 지급한다. 공유 창 열기·링크 복사 기준이며 실제 전송 여부를 확인하지 않는다.
- X·Facebook·기기 공유·링크 복사와 JPG 저장을 지원한다.

## 확률과 데이터

현재 기준은 [BIOMASS_METHOD.md](BIOMASS_METHOD.md)다. 개체수 추첨이 아니라 탄소 생물량 추첨이다. 2018년 전 지구 탄소 생물량을 바탕으로 하며, 바이러스는 제외했다. 육상 야생 포유류 안에서는 2023년 종별 습중량 비율을 사용한 근사 모델이다.

72개 결과에는 종과 상위 집단이 섞여 있다. 식물은 한 집단이며, 대표 사진을 특정 종의 확률로 해석하지 않는다. 인간 확률은 약 0.01008%다. 활성 목록은 `data/categories.json`이다. 개체수 조사는 과거 연구 기록으로 보존한다.

## 이미지와 권리 표시

모든 결과에 300×300 JPG가 있다. CC0·퍼블릭 도메인 50개, CC BY 20개, 생성 개념 삽화 2개다. CC BY는 상업 이용 가능하며 저작자·라이선스·출처·크롭 사실을 결과 화면과 공유 JPG에 표시한다. 생성 삽화는 실물 사진으로 표시하지 않는다.

[전체 이미지 출처](IMAGE_SOURCES.md), [이미지 갤러리](image-gallery.html), `data/category-image-sources.json`에 원본 URL·라이선스·해시를 보존한다. 공개 사이트의 데이터 출처·오픈소스 사용내역에서도 확인할 수 있다. 저장소 전체에 제3자 이미지까지 포괄하는 일괄 라이선스를 부여하지 않는다.

## 개발과 검증

```text
npm install
npm test
npm run assets:verify
npm run build
npm run dev
```

로컬 미리보기는 http://127.0.0.1:4174/ 이다. 빌드는 `docs/`를 생성한다. `SITE_URL` 환경변수로 배포 주소를 변경할 수 있다. 이미지 수집 스크립트는 연구용이며 최종 검수 선택은 출처 목록을 따른다.

Google Tag Manager, Google Analytics, AdSense, Cloudflare Web Analytics는 기존 환생 여권과 같은 공개 게시자 설정으로 포함했다.

현재 결과를 제외하는 다시하기 버튼도 제공한다. 잔여 횟수 1회를 사용하고 현재 결과만 후보에서 제외한 뒤 기존 비중을 재정규화한다. 등록증·OG의 확률은 전체 생물량 기준을 유지한다.

## 기기 공유

친구에게 등록증 보내기는 Web Share API로 기기 기본 공유창을 호출한다. 카카오 SDK·앱 키는 사용하지 않는다. 취소하면 공유 보너스를 지급하지 않는다. 미지원 브라우저는 별도의 링크 복사 버튼을 안내한다.

## 다국어 통합

하나의 리포지토리에서 `/ko/`, `/en/`, `/zh/`, `/es/`를 함께 배포한다. 기존 루트 한국어 주소와 공유 링크는 유지한다. 언어별 소스는 `locales/`이며 `npm run build`가 전체 `docs/`와 모든 언어·결과·출처 페이지를 포함한 사이트맵을 생성한다.

메인 및 결과 페이지의 언어 링크로 수동 전환한다. 저장한 언어가 없으면 GeoJS 국가 조회로 추천하고, 실패하면 브라우저 언어를 사용한다. 강제 리다이렉트는 하지 않는다. IP 자체는 저장하지 않으며 국가코드만 세션에 임시 보관한다. 외부 서비스 이용 안내는 화면에 표시한다. GeoJS 공식 문서: https://www.geojs.io/docs/v1/endpoints/country/

공유는 기기 기본 공유와 링크 복사를 사용한다. Kakao SDK·키는 포함하지 않는다. 이미지 출처와 라이선스·변경 고지를 모든 언어에서 보존한다.
