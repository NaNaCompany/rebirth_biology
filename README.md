# rebirth_biology

다시 태어나면 어떤 생물로 태어날까: 개체수 자료를 바탕으로 만드는 생물 환생 게임.

현재 단계는 데이터 수집이다. 앱과 추첨 확률은 아직 공개하지 않았다.

## 수집 데이터

- 조류 9,700종 세계 개체수 추정과 종별 불확실성 구간.
- 조류 데이터의 속·과·목 집계 2,485행.
- 속·강·과·문 등의 집단 개체수 추정 8개 자료와 범위·단위·중복 관계.
- CC0 관측 사진을 확인한 후보 400종의 출처 URL과 라이선스 메타데이터.
- 퍼블릭 도메인 다시마 삽화 1개.

출처와 적용 제한은 [POPULATION_METHOD.md](POPULATION_METHOD.md)를 참고한다. 공개 데이터의 라이선스는 각 자료에 따른다. 전체 저장소에 일괄 라이선스를 부여하지 않는다.

## 재현

`node scripts/prepare-populations.mjs`로 정규화한 조류 표의 상위 분류군 집계와 후보 학명 대조 결과를 다시 생성한다.

개체수 자료가 없는 종에 동일 가중치나 관측 수 가중치를 부여하지 않는다. 상위 분류군 자료만 있으면 그 분류군 수준의 결과로 다룬다.
